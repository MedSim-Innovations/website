# Accessibility

The MedSim Innovations website is designed and tested to be accessible to people using keyboards, screen readers and browser zoom. The project targets WCAG 2.2 Level AA and includes automated accessibility, keyboard-navigation and reflow checks in `npm run check`.

The site owner also reviewed the website with a screen reader in Google Chrome and at 400% browser zoom on 13 November 2026. This testing supports ongoing accessibility work but is not presented as an independent certification or a guarantee that every user will encounter no barriers.

If you experience an accessibility problem, contact [sales@medsiminnovations.com](mailto:sales@medsiminnovations.com) and describe the page and issue encountered.
