# MedSim Innovations Website: Code Repository

The MedSim Innovations website is designed to:

- Showcase our mission, values, and simulation-based training philosophy  
- Provide detailed information about our products and value pillars  
- Allow prospective institutions (nursing colleges, medical colleges, hospitals) to connect with us  
- Present a clear brand identity through clean design and responsive UI  

This project reflects our commitment to **innovation, transparency, and accessibility** within the healthcare training ecosystem.

## Deployment

Deployment is optimized for **Vercel**, but any Node environment works.
