# Product images

Replace the expected files in this directory to update product-card images. The website automatically uses `product-placeholder.svg` while an expected file is missing.

Use WebP images at a recommended size of 1600 × 1000 pixels:

- `roma-medication-kit.webp`
- `suture-practice-kit.webp`
- `infection-control-kit.webp`
- `nursing-procedure-kit.webp`
- `airway-management-kit.webp`
- `emergency-management-kit.webp`
- `obstetric-kit.webp`
- `neonatal-paediatric-kit.webp`
- `community-bag.webp`
- `complete-skills-lab.jpg`
- `training-programmes.jpg`
- `clinical-pocket-articles.webp`
- `nursekit-pro.webp`
- `student-faculty-uniforms.webp`

If you prefer a different filename or format, update the corresponding `image` value in `data/products.ts`.
